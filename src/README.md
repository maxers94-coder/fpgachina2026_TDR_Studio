# 设计源码

|目录|设计内容|
|---|---|
|ps/|测量控制、健康参考管理、候选定位、距离换算与串口屏交互|
|rtl/|同步激励、ADC/DAC接口、帧平均、参考扣除、相关计算及AXI接口|
|constraints/|硬件引脚与时序约束|
|hmi/current/|配套触摸屏工程|
|[pc/](pc/README.md)|PC实验数据管理平台完整压缩包、启动与数据关联说明|

应用入口为 `ps/main.c`。构建脚本按工程内文件映射准备工具所需目录关系，使用步骤见 `build/reproduction.md`。第三方文件的版权与许可声明保留在对应文件中。
