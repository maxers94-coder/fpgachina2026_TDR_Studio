# 电脑端实验数据管理平台

TDR Measurement Studio 用于管理线缆、异常试件、实验配置、健康参考信息和逐次测量结果，并完成多异常匹配、统计分析以及 Excel、CSV、JSON 和数据包导出。它是配套的 Windows 本地桌面程序，使用 Tkinter 和 SQLite，板卡测量仍由 PS、PL 和触摸屏完成。

## 完整平台与文件位置

- [tdr_measurement_studio.zip](tdr_measurement_studio.zip)：完整平台目录，含源码、启动入口、离线依赖、数据库、备份、样例、测试和已有导出，共332个文件。
- [platform_manifest.json](platform_manifest.json)：压缩包及内部文件的大小、SHA-256清单。
- [板端使用步骤](../../board/usage.md)：接线、建立参考、测量及串口日志保存。
- [生产验收分析数据](../../data/production_acceptance/README.md)：配套的最新CSV、分析表和图，及其与平台数据库的差异。

压缩包保留平台原有文件名及相对目录关系。解压后应保留完整的 `TDR-Measurement-Studio/`，包括 `data/`、`vendor/`、`sample_data/`。平台在工作副本中保存数据库、附件、备份和导出，工程包中的压缩包用于保存完整输入。

## 解压与启动

将平台解压到单独的可写工作目录，不能在ZIP预览窗口内直接启动。以下命令在TDR工程根目录执行，目标工作目录应为空或尚不存在：

```powershell
Expand-Archive -LiteralPath .\src\pc\tdr_measurement_studio.zip -DestinationPath ..\TDR-PC-Workspace
Set-Location ..\TDR-PC-Workspace\TDR-Measurement-Studio
.\start.bat
```

也可以在解压后的目录双击 `启动实验管理平台.bat`。需要安装带Tcl/Tk组件的Python 3.11或3.12。BAT优先使用 `py -3.12`，其次使用PATH中的 `python`；仅安装Python 3.11且BAT无法找到时，在平台目录执行：

```powershell
py -3.11 app.py
```

`vendor/` 已提供openpyxl与et_xmlfile，Excel功能无需联网安装这两项依赖。matplotlib是图表显示和图片导出的可选依赖，未随包提供；缺少时，平台给出图表不可用提示，数据录入、统计及表格导出仍可使用。环境要求见平台目录内的 `requirements.txt`。

在解压后的工作副本中，可以执行以下环境与数据库自检。该命令会初始化运行目录和数据库连接：

```powershell
py -3.12 scripts\check_install.py
```

平台为独立PC程序，不依赖Vivado或Vitis的运行目录。`build/restore_snapshot.py` 准备的是板端构建输入；PC平台按本页单独解压。

## 与板端测量的配合

1. 按板端说明接线、上电并建立健康参考，记录线序、试件和远端终接条件。
2. 在平台选择对应批次及实验配置。单异常选择相应测试板，多异常逐项填写真实试件、安装位置和预期极性。
3. 在触摸屏执行测量，将状态、候选位置、极性和质量标记录入工作台；多条结果可用工作台支持的批量粘贴格式录入。
4. 需要原始数组时，使用 `board/record_log.cmd` 保存串口日志，并在平台将日志或截图作为对应实验的附件保存。
5. 测量完成后核对真实位置与候选的一对一匹配、漏检、额外候选和质量标记，再导出结构化数据及图表。

平台当前提供手工录入、批量粘贴和附件关联，没有UART自动采集、固件指令发送、RAW/CORR自动解析或波形回放。Excel导入用于建立实验计划与资产，不能把串口TXT当作已实现的自动测量导入格式。串口记录工具、VOFA等软件使用同一COM口时需依次关闭或释放端口。

板端 `BASE_ID`、`BASE_CRC` 和 `MEASUREMENT/SEQ` 可写入实验或参考备注，并与原始日志附件关联。平台没有这些字段的自动同步接口；建立健康参考仍在板卡触摸屏上完成，PC中的参考记录用于描述和追溯测量条件。

## 数据目录与备份

解压后的默认位置如下：

|位置|内容|
|---|---|
|`data/tdr_studio.db`|正式工作数据库|
|`data/attachments/`|关联日志和截图等附件|
|`data/backups/`|数据库备份|
|`data/import_reports/`|计划表导入记录|
|`exports/`|Excel、CSV、JSON、图表和分析数据包|
|`sample_data/`|实验矩阵格式样例|

路径由平台所在目录确定，整体搬迁不需要修改代码。需要自定义存放位置时，可在启动前设置 `TDR_DATA_DIR`、`TDR_DB_PATH`、`TDR_EXPORT_DIR`。新建数据目录不会自动复制随包数据库；继续使用既有记录时应先复制数据库，并保留配套附件。

日常备份使用“系统设置”中的数据安全功能。数据库备份与附件应一起保存；仅复制 `.db` 不包含附件。手工复制正在使用WAL模式的数据库时，应先关闭程序，或使用平台的备份功能生成一致快照。

## 随包数据库与正式分析数据

随包平台数据库包含12块测试板资产、161组配置、90个实验运行、230条试次和49个多异常候选。当前生产批次有82组配置；其余配置包含早期计划，未测试计划不能计作已完成试验。原有样例、导入报告和历史元数据随平台保留。

**随包数据库与最新生产分析包不是完全相同的数据快照。** 两者有229条相同试次ID，49个多异常候选的ID、测量值、误差、匹配ID及极性一致，但存在以下差异：

|项目|平台随包数据库|最新生产分析包|
|---|---|---|
|PB16记录|保留接线条件不足的旧记录，状态为未检出、距离为空|采用11月4日补测，真值34 m、测量33.904 m、正常负极性检出|
|多异常25 m试件|PE01、PE02、PE05、PE06的真实异常定义仍关联T8|已按试件清单更正为T9 10 Ω串联|

正式报告和海报的数据依据见 [生产验收分析数据](../../data/production_acceptance/README.md)。平台数据库保留其随附状态，因此直接在该库重新导出的检出率、试件名称或判定结果可能与最新分析包不同。继续维护时，应结合真实试件和原始记录，在平台中核对对应配置及试次，并保留审计记录。

平台导出默认包含全部批次与配置；工作台选择的当前批次不等同于导出筛选。分析时按 `batch_id` 及配置关联筛选。多异常按 `mode=multi` 识别，不能只按PE编号前缀筛选，因为PE07为正常对照。

## 统计口径

- 单异常以试次统计检出与未检出；正常组单独统计正常判定和误报。
- 多异常需区分“试次数”和“真实异常次数”，并统计漏检和额外候选。
- 定位误差只使用符合质量规则的定位值，未检出不当作0 m加入均值。
- `EDGE*`、`PN?`、`OVERFLOW`等标记应原样记录，不能仅凭距离看起来合理就改为普通有效值。
- 理论反射系数由理想电阻模型计算，不代表仪器实测或精密阻抗标定。

详细界面操作见解压后的 `使用说明.md`；数据库、导出字段和统计定义见 `docs/DATABASE.md`、`docs/EXPORT_FORMAT.md`、`docs/STATISTICS.md`。
