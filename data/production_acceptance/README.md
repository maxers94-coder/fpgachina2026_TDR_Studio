# 生产验收分析数据

[report_data.zip](report_data.zip) 保存生产验收报告数据包的完整19个文件，包括Excel分析工作簿、CSV记录与统计、6张实测图表、报告要点和范围校验信息。压缩包和内部文件哈希见 [archive_manifest.json](archive_manifest.json)。

解压到独立分析目录后，主要入口如下：

|包内文件|用途|
|---|---|
|`报告要点.md`|统计结果、数据范围及质量标记口径|
|`validation.json`|批次、数量和关键校验信息|
|`FW63_生产验收_数据分析报告_20261104.xlsx`|分析工作簿|
|`data/trials.csv`|230条逐次记录|
|`data/candidates.csv`|49个多异常候选|
|`data/expected_anomalies.csv`|真实异常定义和试件关联|
|`data/多异常逐异常.csv`|各配置中每个真实异常的统计|
|`figures/`|检出率、定位误差、多异常位置与重复性图表|

## 数据范围

生产批次为 `FW63-PROD-20261102`，包含82组配置、230条单次记录。本批按固定线序执行生产验收，不是独立随机盲测；各组重复次数不同。

|统计对象|正式口径|
|---|---|
|异常试次|184/184检出|
|正常对照|46次正常判定，0次误报|
|有效定位值|213个，全部在±0.60 m内|
|全批定位误差|MAE 0.0856 m，P95 0.2078 m，最大绝对误差0.3220 m|
|综合成功|229/230，约99.57%|
|多异常子集|6组配置、19次试验、49个真实异常全部匹配，无漏检、额外候选或极性错误|
|多异常子集误差|MAE 0.0826 m，RMSE 0.1020 m，最大绝对误差0.2960 m|

PB15的34 m开路记录带 `EDGE*`。正式口径使用 `edge_as_valid=false`，该条不计入有效定位，不能将综合成功率直接写成100%。多异常子集与全批的误差指标使用不同分母，应分别标注。

多异常25 m位置按T9 10 Ω串联解释；其余位置对应T3、T7、T6。通过候选的 `matched_expected_anomaly_id` 关联真实异常的 `id`，再读取测试板和真实距离。筛选试次使用 `mode=multi`，PE07是正常对照。

## 与其他工程数据的关系

- [data/captures](../captures/) 保存板端串口采集、波形和实屏观察记录；本目录保存正式生产批次的结构化记录和分析结果。
- [PC平台](../../src/pc/README.md) 随附数据库为原始平台快照，与本包存在PB16试次及多异常25 m试件关联差异，不能因试次数同为230就视为相同数据。
- 本包用于报告和海报统计，不是平台数据库恢复文件，也不能直接覆盖 `data/tdr_studio.db`。平台源程序、板端镜像与标定输入各自保留原有用途。

试件与接线条件按各次实验记录解释；新增数据条目或更长真值本身不构成硬件连续量程或检测极限的验证结论。
