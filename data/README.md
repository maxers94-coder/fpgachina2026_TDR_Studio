# 实验数据与黄金参考

`captures/` 保存实测文本、波形、会话信息及实验核对结果，覆盖正常直通、端点开短路、弱异常样品、位置变化、多板组合、连续控制和屏幕观察。`vectors/` 为RTL仿真所用黄金向量、系数和参考输入。实验分组见 [data_index.md](data_index.md)。

原始数据保留采集时的设备回显、参考编号、CRC和测量序号，以便配对对应数组。ZIP与解压文件可能同时存在，文件数不等于独立测量次数。

逐点重算需要同一参考和测量帧的RAW与相关数组，避免混用接线状态和测量序号。只有摘要时，可核对范围限于摘要项。设计报告的DCAB四板配置与DACB实屏测试分别统计。

样品定义与定量结果见 `report/competition_report.docx`。VNA数据用于功能预检和相对观察，尚未完成精密反射系数校准。

## 生产验收与PC数据管理

[production_acceptance/](production_acceptance/README.md) 保存配套的生产验收报告数据包，包含82组配置、230条单次记录、结构化CSV、Excel分析表和实测图表。全批统计与6组多异常子集统计分别列明，保留EDGE*质量规则和试件修正口径。

[PC平台](../src/pc/README.md) 的完整源码、SQLite数据库、依赖和已有导出位于 `src/pc/tdr_measurement_studio.zip`。平台随包数据库与上述最新分析包存在PB16试次、25 m试件关联差异；两者的试次数同为230不代表内容完全相同。原始采集文本、平台录入记录和报告分析结果按各自参考条件、批次和试件定义配对使用。
