# 可复用技能包

本项目将定点运算校验、显示数据核对和测量状态管理中的开发方法整理为三个可复用模块，可用于其他嵌入式测量与FPGA信号处理项目。

|技能|用途|入口|
|---|---|---|
|整数黄金参考|基线扣除、相关和直流修正的逐点比对|fixed_point/README.md|
|显示负载核对|字节序列、反向传输与截断定位|display_mapping/README.md|
|测量状态工作流|参考提交、连续停止和结果统一发布|measurement_state/README.md|

各模块说明适用场景、输入输出、使用方法、适用条件及验证结果。整数黄金参考和显示负载核对模块仅依赖Python标准库，提供示例数据与校验脚本；测量状态工作流总结了健康参考建立、测量结果发布及连续测量停止的处理方法。

在工程根目录运行 `python skill/fixed_point/test_checker.py` 和 `python skill/display_mapping/test_payload.py` 可验证两个脚本模块。通用脚本测试结果与系统实板测试结果分别记录，具体适用范围和验证依据见各模块说明。
