# 带参考测量的状态管理方法

本方法适用于先建立正常参考、再执行单次或连续测量的嵌入式应用，可用于背景校正、称重零点和阻抗测量。

输入包括通信状态、参考有效性及编号、测量忙闲、开始与停止请求；输出包括参考提交、完整结果、允许或拒绝操作、停止保持。

1. 分开管理通信在线、参考有效、测量忙闲和结果有效。
2. 在候选缓冲区建立参考，核对长度、序号和校验值后统一提交。
3. 采集和计算期间保留上一完整结果，新结果完成后统一更新曲线、类型和距离。
4. 在安全事务边界处理停止与切页，保留最后完成结果。
5. 低返回结果清除距离，防止旧值被误认为当前结果。
6. 断电或接线变化后重新检查参考适用性。

验证采用“建参考→单次→连续→STOP→切页→恢复正常”动作表，记录状态、完成序号及屏幕观察。本项目的主机回放覆盖状态与失败分支，操作测试确认停止保持、切页停止和低返回清除。迁移到其他设备时需按其实时性、中断和通信模型重新验证。
