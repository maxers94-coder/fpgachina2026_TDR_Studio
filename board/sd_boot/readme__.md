# 系统启动文件

本目录提供SD启动镜像、配套首次启动加载程序、PL位流、测量应用、硬件描述和BIF组成文件。文件名和组成关系按现有工程保持一致。

1. 板卡断电，将本目录 `boot.bin` 复制到FAT32卡根目录并命名为 `BOOT.BIN`。
2. 安全弹出存储卡，按 `boot_switch_reference.png` 的板卡方向设置SD启动后上电。
3. 屏幕显示HOST ONLINE，按正常直通与50Ω配置建立健康参考，再进行测量。

系统已完成SD独立启动和多板显示操作测试。健康参考保存在RAM中，重新上电后需建立。完整使用步骤见 `../usage.md`。
