# 功能范围与测试条件


| 项目       | 功能及测试条件                                                |
| ---------- | ------------------------------------------------------------- |
| 独立运行   | SD卡上电后自动加载程序，触摸屏进入HOST ONLINE状态             |
| 健康参考   | 由正常通路三笔平均帧建立，保存在RAM中；使用正常直通和50Ω终接 |
| 处理链     | PN127、50Mchip/s、200MSPS采样、32帧平均、参考扣除与相关处理   |
| 末端强返回 | 标称0–33m，提供开路样和短路样返回提示                        |
| 弱异常     | 标称1–33m，在多个离散位置和指定样品配置下测试                |
| 多返回     | 局部候选最多8项、屏幕最多6项；已验证四板候选呈现              |
| 观察窗     | FULL显示0–35m，标称验证范围止于33m                           |
| 未验证配置 | 0m弱异常、远端开短路与中间弱异常联合检测                      |
| 阻抗定量   | VNA用于预检，尚未完成精密反射系数标定和检测极限评价           |
| 参考适用性 | 重新上电或改变正常通路结构后需重新建立                        |
| 屏幕文件   | 提供配套HMI源工程，未附经过验证的TFT成品                      |

多异常检出受峰间距、幅度差、旁瓣、遮蔽、噪声和候选容量影响。现有结果支持所测线缆、离散位置及样品组合下的功能表现；连续位置、不同线型和更多组合需另行测试重复性、误检和漏检。
