# Stage38连续距离显示修复

状态：已实现、主机回归和ARM编译通过，等待实际屏幕确认。固件版本为38，PL、平台、屏幕文件、PN激励及冻结距离模型沿用原版。旧Stage35程序和运行配置保留。

## 改动

原版每帧先写-- m，再在新结果完成后写15 m，造成可见交替。新版仅在同一连续会话、页面和参考下保留上一笔已确认的显示值；新结果与当前曲线传输确认后，再提交新的数值或-- m。页面上的LAST COMPLETE / NOMINAL表示显示的是最近完成的名义结果。

每次新测量的计算缓存仍立即失效，不把保留的屏幕文字导出为当前测量。低残差、正峰未拟合或超范围的新结果完成后显示-- m。独立SINGLE/F、新会话、参考变化、PAGE/READY、采集错误均保留清除和失效处理；USER STOP仍保留最近完整结果。显示通道失步时暂停写入，等待READY；通信故障下无法保证实际屏幕收到清除命令，因此不能把残留屏幕字样视为新结果。

主程序222组43048项主机模拟检查通过。新增检查覆盖12个连续帧不插入空距离、数值更新、LOW_RETURN及不支持的参考配置、采集/结果读取/绘图失败、PAGE/READY和STOP。10份完整生产代码模拟输出的2560相关值、5120绘图像素经过独立重算。未用主机结果替代实际LCD观察。

## 加载与短检查

1. Vitis运行配置选择 **Stage38_CONTINUOUS_DISTANCE_DISPLAY_UART0_UART1** 后Run。新配置看不到时重新打开工作区。发送V应有`FW_STAGE=38`，启动文字为`STAGE38 CONTINUOUS DISTANCE DISPLAY READY`。
2. 新Run使RAM参考失效。先接**主机 → 15m线 → 原直通接头 → 5m线 → 同一个50Ω终端**。
3. 在屏幕REFERENCE / CAL页，按`CAPTURE HEALTHY REF`，按钮变为`CONFIRM 50 OHM`后在15秒内再按一次。等待参考成功，随后回MEASURE页。不能带D板建立参考。
4. 关闭VOFA，双击`tools/record_serial_text.cmd`记录。按V确认版本；参考成功后按J保存参考表。如在建参考之前打开记录工具，可同时保留完整B来源记录。
5. 直通下短运行CONTINUOUS后STOP，应为-- m。停止后换同一D1k板（J1朝15m近端），连续运行约5秒：距离应保持约15m，不再反复切换-- m；STOP后保留最后完整值。
6. 停止后恢复原直通接头，再次CONTINUOUS，应在新结果完成后回到-- m。STOP后依次按I、R、C，每项输出完再发下一项，最后按Q结束记录。把SAVED TEXT路径发回，并说明交替闪烁是否消失。

本轮只需确认显示修复，不需要重做5m/10m/15m整套位置测试。若连续运行时发生屏幕错误，保留日志并停止本轮操作。旧Stage35采集脚本有版本检查，不用于本轮；使用上述文字记录工具。
